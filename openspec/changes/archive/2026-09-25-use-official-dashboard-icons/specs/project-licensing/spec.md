## Purpose

The repository communicates the reuse terms for its original source code without claiming ownership of third-party brands or artwork.

## ADDED Requirements

### Requirement: MIT license for original repository code
The repository SHALL include the complete MIT License text governing its original source code and documentation.

#### Scenario: License discovery
- **WHEN** a user or downstream recipient inspects the repository root
- **THEN** they can find the MIT License text and determine the reuse terms for the repository's original material

### Requirement: Third-party asset rights remain distinct
The repository SHALL state that third-party names, logos, icons, and other branded assets remain subject to their respective rights and terms and are not relicensed under MIT.

#### Scenario: Third-party icon is distributed
- **WHEN** the repository includes a third-party service icon
- **THEN** the asset's applicable provenance and terms are identified separately from the repository's MIT license
